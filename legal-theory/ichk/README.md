# Terminology moved — Designed-for-Rejection

The former “ICHK” research mechanism is now framed as **[Designed-for-Rejection](../designed-for-rejection/README.md)**, describing a proposed construction by which material is made to be rejected.

The new entry is authoritative. This page remains only to preserve historical links; the abbreviation has no inferred expansion and this redirect makes no claim that a real mechanism has been implemented or observed.
