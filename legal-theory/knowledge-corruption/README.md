# Terminology moved — Knowledge Antithesis

**Knowledge Corruption** is a former name for the condition now called **[Knowledge Antithesis](../knowledge-antithesis/README.md)**.

The change is a renaming, **not** the creation of an opposing positive condition. Knowledge Antithesis describes knowledge material compromised against reasoned examination or in relation to theory adoption or repudiation.

This page is a compatibility redirect and no longer defines a separate research concept.
